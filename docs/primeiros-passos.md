# Primeiros passos

O caminho de quem chega ao projeto, nesta ordem:

1. **[Instalação]({{ site.baseurl }}/instalacao):** pré-requisitos, o `.env` da raiz, Linux nativo e Windows com WSL2, submódulos.
2. **[Desenvolvimento com serviço no host]({{ site.baseurl }}/dev-local):** a infraestrutura em containers e o módulo em que você trabalha rodando com `npm run dev`, sem refazer imagem a cada mudança.
3. **[Como testar]({{ site.baseurl }}/como-testar):** os testes de unidade de cada módulo e as suítes de `scripts/`, com o que cada uma cobre e quanto demora.
4. **[Glossário]({{ site.baseurl }}/glossario):** os termos e siglas do código, da norma e das reuniões, cada um com o lugar onde aparece.

Depois disso, a seção *Como funciona* explica as peças uma a uma.
