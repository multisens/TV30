## O que é

A TV 3.0 é a nova geração da TV digital aberta no Brasil. Nela, cada canal é visto na TV como uma
aplicação, e a TV oferece a essas aplicações uma plataforma comum, com perfis de usuário, catálogo de
aplicações e APIs para que celulares e outros aparelhos da casa participem. A camada que define tudo
isso é a de Codificação de Aplicações, da norma ABNT NBR 25608.

Este projeto provê um testbed aberto dessa camada: um receptor simulado, inteiro em containers
Docker, ao lado de uma emissora também simulada. Ele foi feito para a pesquisa e o ensino. Não é um
receptor de produção nem um receptor certificado.

## Em três comandos

Num Linux com Docker e Docker Compose v2 (no Windows, dentro do WSL2):

```bash
git clone --recurse-submodules https://github.com/multisens/TV30.git
cd TV30
cp .env.example .env
./tv30 up
```

Abra `http://localhost:8080` no navegador: é a tela da TV. Para desligar, `./tv30 down`. Os detalhes
de cada sistema estão em [Instalação](instalacao/).
